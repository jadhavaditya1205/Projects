Relationships

  • Store to Employee: One-to-Many relationship. Each store can have multiple employees, but each employee works at only one store.
  • Customer to Order: One-to-Many relationship. Each customer can place multiple orders, but each order belongs to a single customer.
  • Store to Order: One-to-Many relationship. Each store can receive multiple orders, but each order is placed at a single store.
